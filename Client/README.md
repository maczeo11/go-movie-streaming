# MagicStream client

React 19 + Vite + TypeScript frontend for the MagicStream API.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api to :8080
npm run build    # type-checks + produces Client/dist
npm run lint
```

The full picture lives in the [root README](../README.md) and
[docs/](../docs/ARCHITECTURE.md).
